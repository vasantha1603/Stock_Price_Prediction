# Stock Price Prediction Using Machine Learning

## 📌 Project Overview

This project focuses on predicting stock prices using historical stock market data and machine learning techniques. The project involves data preprocessing, feature engineering, model training, and evaluation to identify patterns in stock price movements.

## 🎯 Objectives

* Analyze historical stock market data.
* Preprocess and prepare the data for machine learning.
* Identify important features that influence stock prices.
* Train machine learning models for stock price prediction.
* Evaluate and compare model performance.
* Visualize stock market trends and prediction results.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Machine Learning
* Streamlit

## 📊 Dataset

The project uses historical stock market data containing features such as:

* Open Price
* High Price
* Low Price
* Close Price
* Trading Volume

Additional technical indicators can be used to improve the analysis and prediction process.

## 🤖 Machine Learning Models

The project explores machine learning techniques including:

* Random Forest
* Logistic Regression
* Naive Bayes
* Multi-Layer Perceptron (MLP)

The models are trained and evaluated using the prepared stock market data.

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone <your-github-repository-url>
```

### 2. Open the project folder

```bash
cd stock-price-prediction
```

### 3. Install the required libraries

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```
